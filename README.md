# MarioKartDataScience

## Projektübersicht
Dieses Projekt enthält eine SQLite-Datenbank mit dazugehörigen Modellen, Skripten zur Befüllung und Tests.

## Ordnerstruktur
- `models/`: Enthält die Datenmodelle wie User, Score und Strecken.
- `scripts/`: Skripte zur Befüllung der Datenbank.
- `data/`: Statische Datensätze (CSV, Excel).
- `database/`: Werkzeuge zur Erstellung und Verwaltung der Datenbank.
- `tests/`: Unit- und Integrationstests für das Projekt.
- `.env`: Umgebungsvariablen für die Konfiguration.
- `requirements.txt`: Abhängigkeiten des Projekts.
